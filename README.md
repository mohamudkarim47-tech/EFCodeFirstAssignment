# C# and .NET Framework Portfolio

## Introduction
This repository contains the projects and exercises I completed during my C# and .NET Framework course. Through these applications, I have developed a strong foundation in Object-Oriented Programming (OOP), web development, and database management.

## Technical Skills
* **Languages & Frameworks:** C#, .NET Framework, ASP.NET MVC
* **Database & ORM:** SQL, Entity Framework (Code-First & Database-First)
* **Concepts:** Object-Oriented Programming (OOP), LINQ, MVC Architecture, Branching & Logic
* **Tools:** Visual Studio, Git, GitHub

## Featured Projects

### 1. Car Insurance Quote Application (ASP.NET MVC)
A web application built using ASP.NET MVC and Entity Framework. It takes user input (such as age, car make/model, and driving record) and calculates a dynamic car insurance quote based on specific business logic. 
* **Key Skills:** MVC Architecture, Entity Framework, Routing, Razor Views, passing data between Controllers and Views.

### 2. Package Express (C# Console Application)
A shipping quote calculator that evaluates a package's weight and dimensions. If the package exceeds maximum limits, it rejects the shipment; otherwise, it calculates a total shipping fee using a custom math formula.
* **Key Skills:** Branching logic (if/else), user input parsing, mathematical operations.

### 3. Twenty-One Card Game (C# Console Application)
A fully functional console-based Blackjack (Twenty-One) game. It tracks player balances, active gameplay loops, and dealer rules. 
* **Key Skills:** Object-Oriented Programming (Classes, Inheritance, Interfaces), Operator Overloading, and LINQ (to evaluate winning conditions and max scores).

### 4. Code-First Student Database (C# Console Application)
A foundational project demonstrating Entity Framework's Code-First approach. It dynamically generates a SQL database and tables directly from C# entity classes without requiring manual SQL script execution.
* **Key Skills:** Entity Framework Code-First, DbContext, Data Models.
